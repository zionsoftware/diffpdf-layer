# 対応済み・未対応 PDF 構造

更新日: 2026-10-16。基準PDFに対するグループ別の構造比較を行う。PDF全体の一致判定、全PDF仕様の妥当性検証、画素一致の保証は行わない。

| 構造・比較単位 | 扱い |
|---|---|
| 入力2～4ファイル | 1番目を基準に1～3組。比較対象同士は比較しない |
| PDF本体 | Catalogの対応属性、ページ数・サイズ・回転・ページ属性。ページツリーの参照、Count、循環、未知属性も検査 |
| レイヤーなし | OCGに所属しない本文テキスト・画像・パス・注釈・ウォーターマーク等 |
| OCGレイヤー | 任意の非空Unicode名。登録済み単一OCGの描画・注釈とその表示状態 |
| レイヤー名の集合差 | 和集合を用い、新規追加・削除を報告。各組の両方にない名前は省略 |
| 重複名 | その名前を検証不能。他の名前やグループの解析を継続 |
| 壊れたOC参照・OCMD・VE | 未所属へ振り替えない。所属が不明な内容の影響範囲を検証不能 |
| D / Configs、BaseState ON/OFF、ON/OFF、Locked、RBGroups、Intent | 検査して対象レイヤーごとの状態へ射影。関係しないレイヤーを含めない |
| Order / ListMode | 構成の妥当性を検査。レイヤーパネルの表示順や表示方式を内容差にはしない。実描画の順序は別に比較 |
| Usage・ASのView / Print / Export | 限定した状態・Event・Category・登録OCGを検査して対象グループへ比較。所属の決定には使わない |
| 言語・ズーム等のUsage、他のAS、BaseState Unchanged | 影響する状態を検証不能 |
| Text / FreeText / Line / Square / Circle / Polygon / PolyLine / Highlight / Underline / Squiggly / StrikeOut / Caret / Stamp / Ink / Redact / Watermark | 属性・外観・参照リソースを比較。完全なsubtype別妥当性検査ではない |
| OCGに所属しない注釈 | 通常のレイヤーなしの内容として比較 |
| Link + URI Action | URIを開かず、文字列と属性を比較。DEMO専用の例外なし |
| JavaScript・追加アクション・その他の動的Action | 実行せず、その注釈の所属グループを検証不能 |
| Popup / Parent / IRT、Widget、添付、マルチメディア等 | 関連構造の影響があるグループを検証不能 |
| Rect / L / LE / BS / Border / C / CA / F / RC / DA等 | 座標・色・透明度等の値を保持。DAの使用フォントを解決し、RC/DSの限定したfont-familyを分離 |
| P、M / CreationDate / NM | Pは所属ページとの対応を検査。保存日時・識別子は比較から除外 |
| 注釈配列 | 個数を保持したマルチセットで内容比較。交差するRectの注釈順序は合成順序で別途比較 |
| APのN/R/D・外観状態辞書 | Formの暗黙の状態保存を反映し、外観の全命令と使用リソースを比較。内部OCGは未対応 |
| ページTrans | 空辞書は既定の無効果状態として省略と同一視。他の属性は保持 |
| 本文テキスト・パス・色・画像・ExtGState・色空間・Shading | 命令順と使用した参照を比較。Fontを持つExtGStateは未対応 |
| 共有リソース | 使用グループへ取り込む。部分的なExtGState更新を維持し、上書きされた状態は依存から除外 |
| 既定色空間 | DeviceGray / RGB / CMYKで使用するDefault色空間を比較。複合色空間との依存が不明なら検証不能 |
| OCG marked content | `q … /OC … BDC … EMC … Q` または `/OC … BDC q … Q EMC` の独立した単一所属区間 |
| 同一区間の複数グループ・開いたパス/文字状態 | 関係するグループを検証不能。状態が後続へ漏れる場合は影響範囲を広げる |
| q/Q外のクリッピング | グループ間依存を安全に分離できないため、ページの描画グループを検証不能 |
| OC付きForm / Image | 独立した呼出区間なら所属グループへ分離 |
| OCなしForm | 全体の命令を再帰検査。使用したリソースだけを比較。Form内部のOCGは未対応 |
| Artifact / ActualText等の非OC BDC | 辞書・名前付きPropertiesを検査して内容を保持。囲むOCG所属を維持 |
| Fieldsが空、任意のDRだけを持つAcroForm | 使用した既定フォントをDAへ解決。未使用フォントは比較しない |
| 非空AcroForm・XFA・未知フォーム属性 | PDF本体・レイヤーなしと影響する文字注釈を検証不能 |
| StructTreeRoot / OpenAction / Names / 未知Catalog属性 | 影響を限定できないため、そのファイルのグループを検証不能 |
| 循環するオブジェクト / Form / リソース / AP / ページツリー | 検証不能。深度上限も適用 |
| Flate / ASCIIHex / ASCII85 / LZW / RunLength | 展開して比較。ロスレス圧縮差を正規化 |
| DCT / JPX | 符号化データとパラメーターを保持。画素として再展開しない |
| JBIG2 / CCITT / Crypt / 他のフィルター | 未対応。外部バイナリを使用しない |
| Pattern / Type3 / PostScript / 外部参照 / inline image / marked-content point / 互換性セクション / 未知命令 | 関係するグループを検証不能 |
| 暗号化・破損・pypdf警告 | 空パスワードでも暗号化を拒否。ファイル全体を信頼できなければ、そのファイルを含む組のグループを検証不能 |
| Metadata / Info / ファイルID・オブジェクト番号・Generation・格納順・辞書キー順 | 除外または解決・正規化。実際の描画順序は保持 |

## フォントだけが異なる場合

通常の正規化データが一致すれば「一致」。異なる場合にだけ、使用フォントの宣言・埋め込みデータ・Encoding / ToUnicode等と、復元した文字内容・その他の命令を分離した二次比較を行う。

| フォント構造 | 二次比較の条件 |
|---|---|
| Type1 / TrueType / MMType1 | 明示されたStandardEncoding / WinAnsiEncoding / MacRomanEncoding、対応するDifferences、または限定したToUnicode |
| 欧文Base14 Type1 (Helvetica / Times / Courierの12種) | 埋め込みプログラムがない場合に限り、暗黙StandardEncodingを使用可能 |
| Type0 / CIDFontType0・2 | Identity-H + 対応ToUnicodeが必要。CID辞書・Descriptor・埋め込みデータも通常比較では保持 |
| ToUnicode | codespacerange、bfchar、bfrange (範囲・配列)、厳密なUTF-16BE。未定義コード・重複・曖昧なコード長・UseCMap・継承等は推測しない |
| 文字コード変更 | Unicodeのコード単位クラスター、明示配置命令、TJ調整値、Twの0x20規則等が同一と確認できる場合のみ許容 |
| サブセット接頭辞・フォント参照名 | 同じフォントデータで内部識別子だけが異なる場合は通常一致 |
| 埋め込みプログラム・Descriptor・文字マッピング | 文字内容と非フォント構造の一致を確認できる場合だけフォント変更付き一致 |
| DA / RC / DS | DAのサイズ・色等を保持。RCの文字・XML構造・その他のstyleを保持。font-familyだけを二次比較で分離 |
| 自動サイズ・欠落した文字内容・不明なEncoding等 | 通常比較で差があれば、無理にフォント変更付き一致にせず検証不能 |

フォント名はPDF内部名やCSSの申告名として表示する。これは構造比較であり、字形・字幅・各文字の画素位置・フォントプログラムの正当性を保証しない。文字列・明示座標・サイズ・色・透明度・図形・画像・非フォント注釈属性が違えば、フォントのみ変更とはしない。

## 制限と継続動作

- ファイル128 MiB、展開後ストリーム32 MiB、ページ2000、1コンテンツ100,000命令。
- ToUnicodeは最大65,536マッピング。注釈の重なり順検査は1ページ2000注釈まで。それ以上は合成順序だけを検証不能。
- 再帰・正規化ノード数・数値精度の制限。GUIの比較処理は180秒で中止。OSによるメモリー強制上限は設けない。
- 局所的な不一致・検証不能で、他のグループを停止しない。所属・継承状態が不明なら関係する範囲を広げる。解析警告がファイル全体に影響する場合もある。
- 全入力に共通する改変や原本の正しさ、追加した人の身元・履歴は証明できない。基準PDFの選択は利用者が行う。
