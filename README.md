# PDFレイヤー同一性検証ツール（diffpdf-layer）

担当・確認・審査・承認のPDF（2～4個）を比較するWindows向けツールです。**担当・確認は必須、審査・承認は任意**です。指定された最後の工程を基準PDFとして横並びの比較表を作り、全組合せについて内容の一致状況と業務判定を別々に出力します。

## 主な機能

- 対応する文字・図形・位置・サイズ・色・線幅・透明度・注釈・使用資源の内容比較。
- 安全に独立性を確認した描画単位の順序非依存比較。重複オブジェクトの個数を保持。
- 内容判定は一致・不一致・検証不能。追加・削除・フォントのみ変更は不一致として理由を表示。
- 工程ごとの変更許容規則によるPASS・FAIL・UNVERIFIABLE。PDF本体・レイヤーなし・その他のレイヤーは常に一致必須。
- 各ファイルのフルパス・最終更新日時（UTC）・バイト数・SHA-256先頭12桁（例: `abcdef-123456`）を記録。
- 注釈の作成者名（PDF記録値）の名前別件数・未設定件数・構成変更の参考表示。
- GUIでの役割別入力・比較・中止・詳細確認、`cmp.txt`・`cmp.pdf`への保存、CSV・JSON出力、CLI実行。

## 動作環境の概要

検証済み構成はWindows 11、Python **3.14.8 64bit**、Tk **9.0**、pypdf **6.20.1**です。起動処理はPython 3.14系を許可しますが、別パッチ版・Windows各版での動作を網羅確認したものではありません。

通常インストール済みPythonと、手動配置した`vendor/pypdf`のソースを使います。実行時のpip・venv作成・外部通信は不要です。PDF出力だけはReportLab・Pillow・charset-normalizerと日本語TrueTypeフォントも必要です。通常のWindowsではMSゴシックを使用し、フォントをPDFへ埋め込みます。配置手順は導入手順書を参照してください。TkinterはPythonの標準構成を使用し、PDF-XChange Editorは実行依存ではありません。

## 最小限の起動方法

1. オンライン側では、本ツールとpypdf 6.20.1のソースZIPをブラウザーで取得します。プログラムやスクリプトを実行する必要はありません。
2. オフライン側でZIPを手動展開し、pypdfの**内側のpypdfフォルダー全体**を`vendor/pypdf`へ、LICENSEを`vendor/pypdf-LICENSE.txt`へコピーします。
3. `start.bat`を起動し、担当・確認と、必要に応じて審査・承認を指定します。自動表示された基準PDFを確認して「比較開始」を押します。
4. 保存形式にTXTまたはPDFを選び「結果を保存」を押します。既定名は `cmp.txt` または `cmp.pdf` です。

審査を省略し承認を指定するCLIの例:

```bat
start.bat --cli --responsible "C:\PDF\担当.pdf" --confirmation "C:\PDF\確認.pdf" --approval "C:\PDF\承認.pdf" --output "C:\結果\cmp.txt"
```

業務レイヤー名は `担当`・`確認`・`審査`・`承認` に完全一致させてください。`担当者` などは別名のレイヤーとして扱い、自動で対応付けません。

setup.batはありません。配置元・配置先、Pythonの指定、環境確認、CLIは[インストール・セットアップ手順書](docs/installation-guide.md)、操作と結果の読み方は[ユーザーマニュアル](docs/user-manual.md)を参照してください。

## 対応範囲の注意事項

本プログラムは、PDF本体・レイヤーなし・各OCGレイヤーの内容を比較する。オブジェクトの重なり順や視認性は判定しない。チェックマーク・注記の視認性や妥当性は、担当者・確認者・審査者が目視で確認する。これらの役割は一般的な利用例です。

注釈に記録された作成者名は、内容の同一性判定から除外し、参考情報としてグループごとに表示する。作成者名の変更だけでは不一致としない。作成者名は実際の操作ユーザーや最終編集者を証明する情報ではない。

「一致」は対応範囲内の構造比較結果であり、見た目・字幅・記載内容の正しさを保証しません。未対応構造や安全に確認できないグループは「検証不能」です。DEMO描画やURI Linkも通常のレイヤーなしで比較し、特別に除外しません。原本PDFを読み取りだけで解析し、結果の入力PDFへの上書きを拒否します。

具体的な条件は[対応構造一覧](docs/supported-structures.md)、PDF-XChange Editor 11.1.0.0の限定した実出力による結果は[実機検証記録](docs/xchange-validation.md)を参照してください。
